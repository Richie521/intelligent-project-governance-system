This record accompanies the bounded acceptance of v0.1.0-preview.3. Tests ran on 2026-09-27; original failures and corrections remain separate. A successful example does not guarantee every environment or long-term reliability.

## Configuration

The main batch uses gpt-6-astra with low reasoning. The user subsequently selected gpt-6-sol with high reasoning for new validation conversations; the final desktop continuation probe uses that actual configuration and passes. Configurations are recorded separately, without a model comparison or relabeling prior Astra evidence. Native Windows CLI uses 0.158.0-alpha.2.1; WSL uses 0.157.1. Isolated CLI runs use separate user homes, inspect configuration and parent instructions, and disable Hooks, personal memory, plugins and governance Skill injection. Python used by the evaluator is not a basic-installation dependency.

Windows desktop runs use the restarted host with Hooks disabled. Global instructions, available Skills and application tools remain present; desktop results are separate from clean CLI evidence. The coordinator creates synthetic conversations through application APIs to represent confirmed user decisions. They are not private user history or simulated model responses. Three real projects receive authorized basic adoption and bounded read-only checks only.

## Failures And Revisions

Redundant draft backups and unnecessary source-authority reads were retained as failures, corrected at their smallest responsibility boundary, and retested. The first desktop continuation answered correctly but searched personal memory and reread a decision. The next instruction avoided those reads but reused prior-turn state. The final instruction requires the current entry, relevant decisions and actual state in the current turn. A controlled fixture change confirms detection of the new value; evaluator changes are distinguished from product writes.

An initial native conversation read exceeded tool argument limits; legal arguments then returned both complete original inputs. This is recorded as a recoverable tool-call efficiency error, not a reason to expand the installation prompt. Cross-sandbox Windows write refusal, mixed PowerShell module versions, and WSL network faults remain environment evidence with their actual recovery conditions.

## Limits

macOS, long-term reliability and comparative quality or token efficiency are unproven. Native Windows link evidence covers directory junctions; file symlink creation was unavailable under the tested permissions. Cross-sandbox identities may lack access to earlier directories; use normal host authorization, never bypass it. The optional transaction executor does not promise atomic snapshots across multiple files.

Native conversation access depends on the host. The two selected source conversations each had one turn and were retrieved fully without truncation. This does not validate every pagination combination or arbitrary history length. Missing originals must be reported incomplete or provided as selected exports, never replaced with summaries presented as complete source text.

The public package excludes the work specification, private paths, credentials, raw conversations and machine logs. It contains generic implementation, synthetic examples and sanitized conclusions. Historical Hook source is explicitly inactive and unsupported; no tested installation or execution path uses a Hook.
