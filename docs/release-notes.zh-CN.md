# preview.5 发布说明

日常资料保护加入基础接入：普通维护重要资料前确认任务开始前完整内容可恢复，优先复用核实恢复点，必要时才保存逐字节副本并保留旧点；只读、无变化和可靠可重建工作避免多余副本。

原生 Windows 连续维护、同名资料独立恢复、Git 脏/未跟踪内容、迁入后 fresh-session 维护与恢复，以及 WSL 三次成功会话有逐字节证据。真实备份拒绝与链接读取拒绝下安全停止已验证；主动识别全部链接、宿主对话切换、macOS、任意并发原子保护及 token/质量收益未验证。
