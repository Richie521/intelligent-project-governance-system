# preview.6 发布说明

本预览版明确：依据来源判断事实时，要保留用户选定的维护成果；验收须同时核对指定修改和应保留内容；人工诊断按证据解释必要原因，只提出防止复发所需的持续修复。

全新 CLI 会话在 10 个实际项目上下文完成合成限定维护，独立检查核对 40/40 个预期文件状态与 28/28 个路由来源。明确授权重建、孤立错误诊断、双持续原因诊断和一次普通桌面讨论分别完成检查。条件与限制见 [preview.6 验证报告](https://github.com/Richie521/intelligent-project-governance-system/blob/v0.1.0-preview.6/docs/governance-correction-verification.zh-CN.md)。之前的资料保护、安装与迁移证据本轮复用，没有重新运行。

# preview.5 发布说明

日常资料保护加入基础接入：普通维护重要资料前确认任务开始前完整内容可恢复，优先复用核实恢复点，必要时才保存逐字节副本并保留旧点；只读、无变化和可靠可重建工作避免多余副本。

原生 Windows 连续维护、同名资料独立恢复、Git 脏/未跟踪内容、迁入后 fresh-session 维护与恢复，以及 WSL 三次成功会话有逐字节证据。真实备份拒绝与链接读取拒绝下安全停止已验证；主动识别全部链接、宿主对话切换、macOS、任意并发原子保护及 token/质量收益未验证。
