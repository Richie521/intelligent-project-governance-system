# 本版联合验收

[English](integration-verification.md)

本记录对应 v0.1.0-preview.3 的有限验收。它说明实际检查了什么，不把一次成功包装成任意环境或长期运行保证。测试时间为 2026-09-27；历史失败和后续修正分别保留。

## 运行条件

主体实验使用 gpt-6-astra、low；用户随后将新验证对话默认配置改为 gpt-6-sol、high，最终桌面旧会话续接补验已实际使用该配置并通过。两种配置分别记录，不作模型比较，不将 Astra 结果改称 Sol 证据。原生 Windows CLI 使用 0.158.0-alpha.2.1，WSL 使用 0.157.1。干净 CLI 使用独立用户目录，核对配置、上层入口和功能开关，关闭 Hook、个人记忆、插件和治理 Skill 注入。测试脚本所用 Python 不属于基础安装依赖。

Windows 桌面端使用重启后的宿主，Hook 关闭；全局规则、可用 Skill 和应用工具仍然存在，故单独报告，不冒充干净下载环境。合成聊天由测试协调者通过应用接口创建，模拟已确认用户决定；不是用户私人历史，也不是让模拟答案代替模型执行。三个真实项目只进行了获准的基础接入与限定只读任务。

## 结果及边界

| 能力 | 实际证据 | 未扩大作用的检查 |
| --- | --- | --- |
| 基础安装 | 缺少目标时询问，回答后接入；识别有效覆盖入口；原样保留 BOM、CRLF 和正文 | 不默认安装到下载目录，不启用未选功能，重复接入没有额外文件、备份或日志 |
| 指定旧资料整理 | Windows 多套合成资料及 WSL 英文资料完成来源清单、分类、索引和有依据的长期决定 | 业务原件哈希保留，不批量移动；缺失资料明确标记，用户意图和当前实现分开 |
| 原生多会话 | 桌面工具实际取得两个选定聊天的完整原始输入；独立解析后与冻结输入逐字一致 | 只访问所选 ID；183 条编号资料中未批准建议和历史操作引文均未成为执行授权 |
| 旧会话和新会话 | 安装前的旧会话实际续接，新会话自行采用本地路由；受控改动后区分最新配置和旧文档快照 | 旧会话继续指令要求本轮读取当前文件；普通无关任务不读取历史、写治理日志或启动诊断 |
| 增量整理 | 新资料更正已有决定，更新相关索引并保留缺失来源状态 | 没有输出未变来源全文；修改前备份与原件相同，无变化重复操作不写入 |
| 用词与结果归位 | 已选用词、决定、状态和日志在联合任务中正确归位，执行器一次提交 | 未选能力不自动开启，无变化不调用执行器，不产生额外治理循环 |
| 事务失败恢复 | 首项写入后失败回滚、重复请求回放、真实未决日志恢复、外部编辑冲突拒绝 | 不覆盖外部改动，不把失败或不确定写入报告为成功；不承诺多文件原子性 |
| 人工诊断 | 明确命令定位真实有缺陷的规则，经授权最小修改后正反向复验 | 普通纠正不触发诊断，必要历史仍可读取；修复范围是智能体约定，不是机器强制边界 |
| 限定同步 | 可写目标成功、实际不可写目标保留原状；目标新会话采用同步后的规则 | 本地差异和私有哨兵保留，部分失败分别报告，中央登记在验收后更新 |
| 三个已有项目 | 每个项目的实际入口在桌面会话中完整注入，独立只读任务返回正确结果 | 每个只执行一次顶层目录统计，无业务正文读取、无服务启动、无文件写入；未验证其私人历史整理 |

## 失败怎样处理

首次安装中的多余草稿备份、事务任务中不必要的来源预读都被保留为失败；分别收紧备份条件和按需读取，再进行受影响复验。桌面旧会话首次答对但多读个人记忆并重复正文；第一版精简指令又沿用上轮配置。最后要求先读当前入口、再读本轮相关决定与实际状态，并用测试器改变合成配置来确认它真的发现了变化。测试器的受控修改与产品写入分别记录，不把前者冒充原件被产品破坏。

宿主会话工具首次参数超过范围，随后使用合法参数成功取得完整输入。该错误归为工具调用效率问题，没有继续加长产品安装提示词。Windows 跨沙箱身份写入拒绝、PowerShell 版本混用，以及 WSL 网络错误属于环境问题；保留现场并分别验证可运行条件，不把这些失败算作功能通过。

## 版本对应与成本

最终安装提示词的行为版本为 continuation-v8。v6 已验证的基础接入、备份、资料整理和可选工具证据按未变契约复用；v7、v8 只修改旧会话继续指令及双语教程，受影响的旧会话路径另行补验，并对 v8 包执行新的干净 Windows 接入和新旧会话任务。最终 README 与本记录的结果说明不改变安装行为；发布清单记录准确文件哈希。

逐类结果与实测成本见 [脱敏汇总](../evidence/integration-validation.json)。统计包括失败、环境阻断和重试；模型进程成功退出不等于功能通过。输入 token 含缓存输入，推理 token 属于输出细分；无法取得的指标标为不可用。总额不包含主代理全部实施或审阅代理开销，不是账单，也不能据此宣称节省百分比。

## 支持限制

测试不能证明长期绝对稳定、相对无治理方案更好或更省 token。macOS 未测试；原生 Windows 文件符号链接因权限无法创建，该批实际覆盖的是目录 junction，不能推广为所有链接类型。不同隔离身份可能没有旧沙箱目录的写权限，必须按宿主正常授权处理，不能绕过。

原生聊天读取取决于宿主工具。此次两个来源各一轮，完整取得且无截断；它不能证明任意长度、所有分页组合都可自动完整整理。原文不可取得时必须报告缺口或使用指定导出，不得用摘要冒充完整原文。多项长期决定和完整性始终以用户确认的资料范围为准。

公开包排除工作 spec、私人路径、凭据、原始聊天和机器运行记录，仅提供通用实现、合成示例与脱敏结论。Hook 代码只保留为明确停用的历史源文件，不属于本版安装或运行路径。
