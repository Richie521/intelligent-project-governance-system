# 三条落地流程联合验收（v0.1.0-preview.4 发布候选）

[English](three-flow-verification.md)

三条流程已在下述合成资料和宿主条件下完成联合验收；本页记录 preview.4 候选的检查结果，正式附件及下载回读状态以发布页为准。流程包括新项目轻量接入、旧项目原地整理、旧项目选择性迁入独立新目录。“删繁就简”只涉及资料和结构，不包含业务逻辑重构。

| 流程 | 已核实的完整链路 | 适用边界 |
| --- | --- | --- |
| 新项目 | 原生 Windows 冻结安装提示词只创建必要入口；全新会话读取入口并完成普通工作。无关只读任务未加载历史、诊断或事务 | 证明该合成项目与测试宿主的轻量路径，不默认启用未选功能 |
| 原地整理 | Windows 留出资料覆盖多文件、多轮真实用户原文、实际分页补读、后续更正、决定与当前配置区分、资料变化后的增量更新；业务原件哈希保持不变。桌面 Sol high 新会话采用归位资料，旧会话续接按当前入口核对 | 无法取得必要原文时保留缺口，不能把摘要当原文；旧会话命令工作目录不等于宿主绑定目录 |
| 迁入新目录 | Windows 留出主链及 WSL 英文链验证方案、选择性复制、路径修复、独立目标运行、重跑和保留后续编辑的撤回。v5 真中断后，Windows 与 WSL 全新目标会话均从索引核对同包安装契约并补齐入口；无运行授权时不执行项目脚本。另获明确授权后，旧源原路径受控不可用时从目标运行报价得到 24，源和目标哈希得到核对 | 只证明这些合成项目的依赖；旧桌面会话能否实际切换宿主目录未获证明，故从新目录开新会话承接 |

迁移默认保留旧项目，首次目标已有内容则停止，不覆盖或静默合并。目标来源索引记录获准范围、同包安装文件身份、本轮创建文件和最终哈希；恢复只处理可核实属于本轮且未被后来修改的内容，索引默认保留。已排除的历史材料可有明确来源出处，目标入口不得保留不存在的相对必读路由。安装或中断恢复只做非执行文件检查；迁移或“保留工作能力”本身不授权运行脚本或服务，运行验证须当前用户明确授权。

首次失败均保留：早期收据只留在旧会话答复中，新会话不能安全撤回；v3 索引拒写后出现竞争补记和缺八原则的入口；v4 可写恢复虽补入口，却越权运行报价脚本且保留失效 notes/ 路由。最小修复落在双语迁移说明：先记录并核对同包安装契约，原索引拒写即停写；只保留目标适用的旧入口规则，运行权限与文件迁移分别判断。v5 的 Windows 和 WSL 定向复验中，恢复轮没有执行脚本、入口原则及路由正确；另行明确授权的普通工作轮才实际运行。Windows 跨隔离会话的既存文件写权限须预先可用；测试器只为合成目标调整 ACL，安装包不会自动修复任意目录权限。

冻结证据按影响复用：v3 的未变运行、重跑和撤回链没有冒称为 v5 全新执行；v4 补验真实中断与同包双哈希；v5 仅两份迁移说明变化，对运行授权和失效路由作 Windows/WSL 定向补验。桌面八条 Sol high 会话另有独立宿主轨迹；Windows CLI 的 44 个唯一 Sol high 回合耗时 7181.527 秒，37 轮已知 input 6,959,892（cached 5,922,176）、output 302,618 tokens，7 轮中断或设施失败用量未知。WSL v3 七轮、v4 三轮、v5 五轮分列，不能把中断未知记零或用文本变短推断节省。模型及检查者各自只对实际轨迹负责，不提供相对无治理系统的成本或质量提升结论。

测试没有扩大三个真实项目既有基础接入授权，没有扫描其私人历史或实施业务迁移。基础安装无须预装 Skill、Git、Python、Hook 或事务工具；测试设施所用工具不转嫁给用户。未验证 macOS、任意权限或链接组合、长期可靠性及所有外部依赖。发布验收还取决于独立复核公开文件清单、全部拟公开 Git 引用、标签及附件的隐私，核对包哈希和链接，并从 GitHub 重新下载回读。正式发布状态及当前附件以发布页为准。
