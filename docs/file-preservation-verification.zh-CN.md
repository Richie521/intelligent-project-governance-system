# 日常资料保护：preview.5 验收报告

preview.5：列明条件下新增能力验收通过，发布包身份见 manifest 与 checksum。本文只说明 preview.5 新增的日常资料保护；preview.4 的三条接入流程仍由[历史报告](three-flow-verification.zh-CN.md)单独说明。

## 已取得证据

普通维护先保护重要资料的任务开始前完整内容，优先复用已核实恢复点，必要时保存项目内逐字节副本；保留旧恢复点、原相对路径、编码与换行。只读、无变化和可靠可重建的临时产物不产生多余副本。Git 已提交、未提交和未跟踪内容分别判断。

原生 Windows 独立会话覆盖普通维护、连续任务、预留资料与同名 sibling 原件恢复、既有恢复点、Git 脏/未跟踪内容。开发组完成 28→35 天维护、下一会话恢复 28 天原件及第三会话恢复 sibling archive 原件；当前文件保持不变。迁入目标两个独立会话在源不可读的条件下完成 21→28 天维护和下一会话的 21 天逐字节恢复。完整成功证据包含 exit 0、当前线程 usage、`gpt-6.1-sol/high`、入口采用、无额外 Skill/memory/Hook 和逐字节检查。

真实备份写入被拒时，模型停止覆盖，原件未变。链接目标读取实际被拒时，模型停止，外部文件未变并保留链接；这只证明真实拒绝下安全停止，不证明主动识别所有链接边界。

WSL Ubuntu 上安装、后续资料维护和 fresh-session 恢复三次成功会话通过逐字节检查。实际入口与有效指导链均为 4049 UTF-8 字节；后来原件的 BOM、CRLF 和其他内容保留。WSL 结果与原生 Windows 分开，不互相代替。

## 失败与支持限制

首次失败保留并区分产品、设施和宿主问题；缺失回执或 usage 的旧尝试不算通过。一项开发维护的模型已完整成功，外层中文打印失败；依据保存的当前线程、快照与字节验收恢复记录，未重发模型请求。迁移的一次旧 wrapper 保持不完整同会话 artifact 状态，后续独立维护与恢复另有完整证据。

本轮是合成资料的有限验收。未验证主动识别全部 junction、宿主对话迁移/切换、macOS、任意并发下原子保护、长期可靠性或相对无治理对照的 token/质量收益。规则是智能体指令，不是系统级拦截；恢复不得覆盖后来成果。旧诊断改动保留原字节和旧证据范围，本轮不提升其验证强度。
