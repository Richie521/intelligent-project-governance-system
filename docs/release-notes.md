# preview.5 release notes

Daily protection joins basic adoption: before ordinary maintenance, the agent establishes recoverable complete task-start content, reuses verified recovery points and creates byte-identical copies only when needed, retaining older points. Read-only, unchanged and reliably reproducible work avoids extra copies.

Native Windows continuous maintenance, independent same-named file recovery, dirty/untracked Git protection, fresh-session maintenance/recovery after migration, and three WSL sessions have byte-level evidence. Safe stopping under real backup denial and denied link reads is verified. Proactive recognition of every link, host handoff, macOS, arbitrary concurrent atomic protection and token/quality gains remain unverified.
