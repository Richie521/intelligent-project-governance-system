# Demo Project Example

This is a sanitized example of how an adopted project can describe its local governance shape.

## Local Entry

```text
AGENTS.md
```

## Local Strengths

- Clear topic map.
- Source files separated from generated reports.
- Historical handoff notes marked as evidence only.
- Task closeout includes a writeback result.

## Source Boundary Example

```text
src/             current implementation
docs/            durable project docs
reports/         generated evidence
run-archives/    machine output, not default context
handoff/         historical evidence only
```

## Privacy Boundary

Do not publish credentials, account identifiers, raw logs, raw conversations, or local machine paths.
