# Contributing

Contributions should improve the reusable governance method without adding private project context.

Before opening a pull request:

- Keep examples sanitized.
- Do not include local absolute paths, credentials, raw logs, or raw conversations.
- Explain whether the change affects routing, authority, verification, safety, decisions, patterns, sync behavior, or public release position.
- Prefer small changes that can be verified with representative probes.

If a proposed change only fits one project, keep it in that project's local governance files instead of adding it to the central method.
