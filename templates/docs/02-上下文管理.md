# 上下文管理

本项目应让后续智能体任务能够安全、快速地开始。

## 任务生命周期

```text
确定当前任务
→ 声明读取范围和排除项
→ 读取最小相关上下文
→ 需要修改时先确认授权
→ 验证行为
→ 报告写回结果
```

## 默认不读取

- 日志
- 缓存
- 生成产物
- 私密笔记
- 原始对话
- 历史快照
- 机器运行档案

只有当前任务需要这些证据时才读取。

## 治理文件语言

使用 `AGENTS.md` 声明的 `zh-CN` 或 `en`。接入时没有有效声明，才比较用户主要交流语言和现有治理入口主要语言；两者一致时选择，冲突或不明确时只询问一次，并在获准执行时固化。不能因后续单轮对话使用另一种语言而切换。

语言选择只覆盖人读治理文件和项目入口，不批量翻译业务文档、代码、供应商文件、运行产物或历史快照。

## 统一用词

本节只在用户明确批准统一用词后保留。启用项目由本地入口声明现有专题文档或确有必要的项目用词表为承载面；未启用项目不建立声明、承载面、空表或探针。新对话在入口后读取一次，上下文压缩后再读取一次；同一上下文只在承载面变化或涉及命名和实质用词时刷新。无害变体静默统一，实质差异触发确认，未确认内容不写回。

## 持久知识

只有结果改变未来路由、权威、验证、安全、决定或复发诊断时才写入长期文件。

## 持久承载面

职责合适时复用现有文件。执行获准、职责和路径明确且不改变来源权威、隐私或长期结构时，可以建立聚焦专题并同步更新主题地图；高影响变化先确认，讨论阶段推迟写回，一次性内容留在对话中。只有文件角色或权威变化时才更新来源权威或文件清单。

## 治理事件日志

`docs/04-治理日志.md` 是固定入口。项目按月或按领域保存事件时，由该入口路由到实际日志，不能并行维护两份事件正文。

只有改变未来治理状态或保存解释实质结果所需证据时才记录。优先复用现有开发日志、故障历史、审计或项目日志；没有合适承载面且事件会反复发生时才建立治理日志。普通读取、一般讨论、无变化探针和每次技能调用不记录；只有产生可复现产物时才建立机器运行档案。
