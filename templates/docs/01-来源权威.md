# 来源权威

定义本项目哪些文件或系统是权威。

## 权威层级

| 层级 | 示例 | 权威 |
| --- | --- | --- |
| 来源 | 当前实现、规范数据、产品规则 | 行为权威 |
| 项目文档 | 专题文档、决定、架构说明 | 当前有效时为权威 |
| 治理文件语言 | `AGENTS.md` 中的 `zh-CN` 或 `en` 声明 | 人读治理文件和项目入口的语言权威 |
| 已确认用词 | 仅在用户批准统一用词后声明的承载面 | 本地用词权威 |
| 治理日志入口 | `docs/04-治理日志.md` | 稳定日志路由；可以指向月度、开发或分域日志，不复制事件正文 |
| 生成产物 | 构建输出、导出、报告 | 除非明确指定，否则只是证据 |
| 运行状态 | 数据库、日志、进程状态 | 当前行为证据 |
| 治理事件历史 | 现有项目日志或获准的治理日志 | 过程证据，不替代当前状态或稳定决定 |
| 历史材料 | 交接、旧对话、快照 | 仅作证据 |
| 私密材料 | 凭据、账号数据、私人笔记 | 不进入默认上下文 |

## 冲突规则

材料冲突时说明哪一层是权威及原因；完成验证前保留不确定性。当前任务以用户最新指示为准；历史计划和交接材料只作证据，不能覆盖当前请求。
